# Maths practice app

A small web app for one Grade 7 student: ten minutes of maths a day, spaced repetition, worked steps after every answer. Built with React, TypeScript and Vite; progress is stored on the device only.

- `npm run dev` — run locally
- `npm test` — engine, content and end-to-end tests
- `npm run build` — static site in `dist/`

Published automatically to GitHub Pages on every push to `main`.
